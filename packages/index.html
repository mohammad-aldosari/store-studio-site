كيف يدفع زبونك؟

وكيف تدفع لنا؟

التأسيس: نص المبلغ عند الاتفاق والنص الثاني قبل الإطلاق. الاشتراك تدفعه مقدم (شهري أو سنوي أو 3 سنوات)، ولكل دفعة فاتورة عربية بالريال.

أسئلة ثانية

كم تعديل أقدر أطلب؟

جولتين تعديل على الشكل قبل الإطلاق، وبعدها تعديلات صغيرة كل شهر حسب باقتك: 1 أو 3 أو بلا حد.

كيف أستخدم لوحة التحكم؟

نسلمك مع المتجر شرح مصوّر بالعربي خطوة بخطوة، وترفع منتجاتك وصورك بنفسك.

وش يصير إذا خلصت المساحة؟

يوقف الرفع بس، وما ينحذف شي. نزيد لك المساحة بـ 15 ر.ق بالشهر أو ترقي باقتك.

اسم الموقع (الدومين) على مين؟

في باقة «متجر» و«احترافي» نربط لك رابط باسم متجرك ويكون مسجل باسمك. رسومه السنوية تدفعها للشركة اللي تسجله مباشرة.

تسوون متجر لأي منتج؟

لا. ما نسوي متاجر لمنتجات ممنوعة أو مقلدة أو مخالفة للقانون والآداب. شوف سياسة المحتوى الممنوع.
